## ✨ What it does
Upload any PDF → ask questions in plain English → get instant AI-powered answers.
No more manually searching through 100-page documents.

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React.js |
| Backend | Node.js · Express.js |
| AI Engine | Groq LLM API (fast inference) |
| Deployment | Vercel |

## 🚀 Features
- 📤 Upload any PDF document
- 💬 Ask questions in natural language
- ⚡ Fast AI responses via Groq API
- 📱 Fully responsive UI

## 🏃 Run locally
```bash
git clone https://github.com/vaishnavisingh025/docuchat
cd docuchat
npm install
npm start
```

## 🔑 Environment Variables
```env
GROQ_API_KEY=your_groq_api_key_here
```
